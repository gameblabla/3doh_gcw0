Load required 3DO files

The emulator will not start until a BIOS and a game image are loaded into their own slots.

Use the two large boxes below. Drop bios.bin into the BIOS box and drop a .iso or .cue + .bin image into the game box, or press the matching Choose button.

Loading files

  1. Put the 3DO BIOS file into the left box. The expected test filename is bios.bin.
  2. Put the game disc image into the right box. ISO files can be selected alone; BIN/CUE games must be selected or dropped as a pair.
  3. Choose PAL1 if the BIOS/game uses the 320×288 PAL mode; Auto only uses filename hints in the browser.
  4. When both boxes show a filename, press Start emulator.

Dropping BIOS and game files on one place is intentionally rejected; BIN/CUE pairs belong together in the game slot.
